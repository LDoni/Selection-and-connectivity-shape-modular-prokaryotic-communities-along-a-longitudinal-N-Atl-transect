

Scripts used for the paper "Environmental selection structures the modular prokaryotic community turnover along a longitudinal North Atlantic transect"

The scripts are organized in: 
  -1) scripts to prepare the tables/files used in the analysis and dor generate the figures 
  -2) scripts to generate the figures


Large intermediate objects such as SparCC matrices and Parcels trajectories are not included

FASTQ files are deposited in the permanent NCBI repository, at the PRJNA1494857 bioproject.
